# Working in this repository

Two different jobs, two different files.

**Editing the repository** — a law card, a comparison, a correction: read
[`CONTRIBUTING.md`](CONTRIBUTING.md) and [`docs/README.md`](docs/README.md) (both are binding), then run
`node scripts/check-docs.mjs`.

**Answering a question** about how the EU or China regulates AI or data: follow
[`skills/ai-governance-compare/SKILL.md`](skills/ai-governance-compare/SKILL.md). Never answer those from
memory — the point of this repository is that every key claim points back at an official source and
carries the date it was last checked.

Rule zero either way: **nothing enters this repository without a source.**
